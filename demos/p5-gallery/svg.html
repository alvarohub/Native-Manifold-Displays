SVG paths + font outlines

p5 extracts the font curves; our existing SVG parser flattens them. Sketch source.

The generated cubic-Bezier SVG heart and “hi” outlines move on a torus. No raster texture here: projected line segments are clipped to source triangles. This accepts SVG path data, not an arbitrary styled SVG document. Font: Archivo Black via Google Fonts (remote asset).
